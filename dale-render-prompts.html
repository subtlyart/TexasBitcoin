Mascot render kit

Dale, on demand

Everything needed to generate Dale the Whaleonghorn — same hat, same aviators, same pool — across every post. Paste the two locked tokens into any image model, then append one scene prompt. The tokens are what keep him from drifting into a different longhorn every time.

THE LOCKTwo tokens, pasted every time

Character token — paste first, verbatim

A single Texas longhorn with long symmetrical horns and warm tan-and-white hide, wearing a comically tiny brown felt cowboy hat perched between the horns and small mirrored aviator sunglasses, deadpan serene expression.

Style token — paste second, verbatim

Glossy 3D Pixar-style render, soft cinematic lighting, shallow depth of field, warm Texas color grade (dusty gold, turquoise water, big sky), clean and uncluttered composition, subtle film grain, square 1:1 framing with empty headroom at the top for a caption.
  • 1Lock a seed. Once one Dale looks right, reuse that exact seed on every later prompt so his face stays identical. This matters more than any wording.
  • 2Keep horns symmetrical. Models love to warp them — the word "symmetrical" is in the token for a reason; keep it.
  • 3Never ask the model for caption text. Generate clean images with headroom and set the type yourself in Canva/Figma. AI text rendering is unreliable and off-brand.
  • 4Render big. 2048×2048, then downscale for posting. Keep the master.
  • 5One character, infinite scenes. Only the scene line changes between posts. That repetition is the brand.
